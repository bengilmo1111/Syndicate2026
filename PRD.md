# 2026 Bulldog Remake PRD

## Vision
A browser-playable 2026-era remake of the classic 1993 Syndicate/Bulldog game, blending top-down tactical combat with retro cyberpunk presentation.

## Objectives
- Deliver a playable browser prototype quickly
- Preserve the strategic agent combat feel of the original
- Add modern cyberpunk visuals and a strong HUD
- Build the game in HTML/CSS/JavaScript for Chrome and Edge

## Target Audience
- Fans of classic Syndicate-style tactical shooters
- Browser gamers who enjoy cyberpunk and strategy
- Players who like single-player missions and upgrade progression

## Scope
### In scope
- Single-player top-down tactical gameplay
- One prototype mission with agent movement, shooting, enemies, and objectives
- HUD showing health, weapons, ammo, and objectives
- Basic upgrade/shop flow
- Cyberpunk UI theme and city tile visuals

### Out of scope (initial)
- Multiplayer or networked gameplay
- Full campaign/story mode
- Full city simulation and finance economy
- Complex 3D rendering or advanced shaders

## Core gameplay pillars
1. Tactical agency: control agents in dangerous city sectors
2. Progression: weapons, armor, and upgrades
3. Cyberpunk atmosphere: neon UI, city grit, futuristic HUD
4. Browser accessibility: simple keys/mouse controls and clean interface

## Success metrics
- Game loads and runs in a browser
- Agent movement and shooting feel responsive
- Enemies behave and present a challenge
- Mission objectives are clear
- UI effectively communicates state and player resources

## Platform / Tech
- HTML5 canvas or lightweight web game engine
- JavaScript for game logic
- CSS for HUD/menu styling
- Placeholder assets for rapid iteration

## Risks
- Performance when many entities are active
- Balancing scope versus polish
- Choosing the right engine for rapid browser prototyping
